# Game Concept

## Fantasy
The player is a "street hat stylist" transforming a neighborhood by placing hats on passersby and key characters.

## Tone
- Bright, pop, playful.
- Slight absurdity grounded in everyday city life.
- Never violent or mean-spirited.

## Session Shape
- 1 run = 5 turns.
- Turn progression moves from onboarding to build climax.
- Final turn includes high-impact targets and summary judgment.

## Player Decisions
- Which target to prioritize.
- Which hat to throw.
- In what sequence and timing.
- Which buffs to lock in after each turn.
