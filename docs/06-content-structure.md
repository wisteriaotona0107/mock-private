# 06 Content Structure

各セクションで「役割 / 伝えること / 必要テキスト / 必要画像 / CTA / 更新頻度」を定義。

- Hero: 空気提示 / 店名・短文 / 全景 / 予約・アクセス / 四半期更新
- Concept: 店の姿勢 / 価値観3点 / 抽象写真 / なし / 半年
- Experience: 過ごし方 / 一人・二人導線 / シーン写真 / 来店案内 / 半年
- Drinks: 主軸酒 / 代表銘柄 / グラス写真 / メニューへ / 月次
- Foods: 小皿提案 / 3-6品 / 料理写真 / メニューへ / 月次
- Space: 席と音 / カウンター・テーブル説明 / 空間写真 / 予約へ / 四半期
- How to spend: 滞在モデル / 60分・90分 / 補助写真 / 初回案内 / 半年
- Menu/Seasonal: 更新情報 / JSON連携表示 / 季節画像 / 詳細へ / 週次-月次
- Access: 行き方 / 住所・時間 / 外観 / Map / 変更時
- Reservation/Contact: 連絡導線 / 予約方法 / なし / 予約 / 随時
- FAQ: 不安解消 / 初回質問 / なし / 問合せ / 随時
- Footer: 最終導線 / 基本情報 / ロゴ / SNS等 / 随時
