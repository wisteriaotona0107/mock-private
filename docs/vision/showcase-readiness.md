# Showcase Readiness

## Purpose
この文書は、将来このリポジトリや関連プロダクト群を外部へ見せる際に、最低限どの整理が必要かをまとめる素案です。

## What External Viewers Will Need
外部の閲覧者が知りたいのは、単なるファイル一覧ではありません。

- 何を目指しているのか
- 現在どこまでできているのか
- どこが構想段階なのか
- どのような利用価値があるのか
- どのように今後育つのか

## Minimum Readiness Checklist
### Product narrative
- 課題設定
- 解決したい体験
- 対象ユーザーまたは利用シーン

### Architecture narrative
- なぜこの構造なのか
- どこまで共通化しているのか
- 現在の責務分離はどうなっているのか

### Operational narrative
- どのように変更管理しているか
- AIをどう運用しているか
- 品質をどう担保するか

### Repository narrative
- 読み順
- 主要ディレクトリの意味
- 現在地とロードマップ

## Current Gap
現時点では、showcase readiness はまだ準備段階です。

- 実装デモがない
- 主要ユースケースが確定していない
- 技術選定の説明が未整備
- 価値提案の具体例が不足している

## Next Steps Toward Showcase
1. 実際のアプリ/機能候補を明記する
2. デモ可能な最小単位を1つ作る
3. 現状と構想の境界を図または表で示す
4. 変更管理・ロール運用の実績を蓄積する
5. READMEから一貫した説明導線を作る
