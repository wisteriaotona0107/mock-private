# UI/UX Principles

## Platform & Posture
- iPhone portrait-first.
- One-handed operation.
- Sub-1 minute onboarding clarity.

## Interaction Feel
- Upward flick is primary action.
- Generous correction at low-mid difficulty.
- Precision requirement rises on difficult targets.

## Information Hierarchy
1. Targets and their state
2. Current hat options
3. Turn/score/combo/theme
4. Feedback and reaction

## Avoid
- Overcrowded HUD
- Excessive tiny text
- Gacha-ad-like visual noise
