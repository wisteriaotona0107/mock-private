# priority_matrix

## Must
- コピー: High優先度IDを主軸にする
- 写真・ビジュアル: 暖色・木目・小規模空間を守る
- UI: スマホで読みやすい余白と文字サイズ
- 法務・衛生表現: 責任境界を曖昧にしない
- 店主の人格: 押し付けず、案内役として示す
- 持ち込み可: 文化として提示（節約訴求禁止）
- 日本酒: 温度帯・飲み比べなど専門性を示す
- 予約・アクセス: 終盤で自然に到達できる導線

## Should
- コピー: Mediumをセクション補助に活用
- 写真・ビジュアル: 手書き黒板・小皿の生活感
- UI: Hero→Concept→HowToの流れを明快に
- 法務・衛生表現: 「お願い」調で角を立てない
- 店主の人格: 短文メッセージで思想を明文化
- 持ち込み可: 具体例（缶詰/惣菜/乾き物）を明示
- 日本酒: その日提案の運用感を示す
- 予約・アクセス: CTA文言は押し売りにしない

## Could
- コピー: LowをSNS/脚注へ転用
- 写真・ビジュアル: 季節の小物で変化演出
- UI: スクロール連動の控えめ演出
- 法務・衛生表現: FAQ化で理解補助
- 店主の人格: 来店後の楽しみ方コラム
- 持ち込み可: 事前相談の簡易フォーム
- 日本酒: ペアリング事例の短冊表示
- 予約・アクセス: 地図連携の補助情報

## Avoid
- コピー: 激安・食べ放題・無制限の語彙
- 写真・ビジュアル: ネオン過多、宴会密集、雑然卓上
- UI: 情報過多で重い1st view
- 法務・衛生表現: 「何でも持込OK」断定
- 店主の人格: 上から目線、常連優先の排他性
- 持ち込み可: 店側が調理/保管する前提
- 日本酒: 単なる銘柄自慢で体験不在
- 予約・アクセス: 強い煽りCTA
