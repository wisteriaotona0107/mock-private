# Buff & Build System

## Turn-End Choice
After each turn, present ~3 buffs; player picks 1.

## Buff Categories
1. Hat Enhancement (e.g., Crown +50%).
2. Throw Enhancement (aim assist, speed, just-window).
3. City Shift (tourism, food culture, kingdom mood).
4. Risk Buffs (higher multiplier with harsher penalties).

## Build Identity
A run should naturally express a style, such as:
- Fashion control
- Food district growth
- Kingdom hype
- Precision throw specialist
- Chaos gambler

## Balancing Heuristic
- Keep at least one "safe" buff option each turn.
- Risk buffs should advertise downside clearly.
