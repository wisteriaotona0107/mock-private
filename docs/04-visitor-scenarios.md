# 04 Visitor Scenarios
## 1) 仕事帰りに一人で立ち寄る
- 不安: 浮かないか
- LP確認: カウンター写真、価格帯、滞在目安
- 後押し: 「一杯だけでも歓迎」
- 避ける: 通向け専門用語の連打

## 2) 知人と静かに話したい
- 不安: 騒がしくないか
- LP確認: 席間、音量感、テーブル席有無
- 後押し: 「小さな会話がしやすい」
- 避ける: パーティー訴求

## 3) お酒を試したいが詳しすぎる店は緊張する
- 不安: 知識を試されないか
- LP確認: 初心者向け案内、おすすめ
- 後押し: 「好みに合わせて提案」
- 避ける: マニア基準の序列表現

## 4) いつもの店とは別の場所を探している
- 不安: 外れだったら困る
- LP確認: 店の哲学、写真の誠実さ
- 後押し: 「日常の延長で立ち寄れる」
- 避ける: 過剰演出写真

## 5) 初めてだが入りやすさを確認したい
- 不安: ドレスコード/常連圧
- LP確認: 入口写真、FAQ、予約可否
- 後押し: 「初めての方へ」導線
- 避ける: 排他的ルールの強調
