# copy_patterns

「Pattern A」「ID 1」のように指定して利用してください。

## 運用ルール
- 主軸は原則 High から選ぶ。
- Medium はセクション見出し/サブコピーで補助利用。
- Low はSNS投稿や限定セクション向け。
