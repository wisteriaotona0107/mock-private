## セクション詳細

### 1. Hero
- 主メッセージ：
  - 「備えるために、ふだん食べる。パックご飯で始めるローリングストック。」
- サブメッセージ：
  - 日常・疲労時・非常時を1本の導線でつなぐ。
- 初動CTA：
  - 「最小セットを見る」
  - 「食事パターンから選ぶ」

### 2. パックご飯を備蓄の軸にする理由
- コア式：
  - 主食（パックご飯）+ 塩味 / 油 / 香り / タンパク質 / 温度感
- 価値訴求：
  - 主食固定で献立意思決定を軽くする。
  - 食品カテゴリを跨いでも組み合わせやすい。

### 3. 賞味期限とローリングストックの考え方
- 賞味期限目安の比較表（注記付き）。
- 「目安」であること、商品表示確認が必要であることを明記。
- 先入れ先出し・期限近接消費の原則を図解。

### 4. 6つの食事パターン
- 丼化系 / 卵系 / 缶詰系 / ふりかけ・混ぜ込み系 / 冷凍食品系 / 汁物投入系。
- 各カードに「満足度」「手間」「保存性」「疲労時適性」タグを付与。

### 5. 味変レイヤー
- 香り・辛味・食感・酸味の4レイヤーで整理。
- 同一ベースを飽きずに回すための補助導線を提示。

### 6. シーン別おすすめ構成
- 超省エネ運用
- 疲労回復寄り
- 防災寄り
- 3つを比較カードで提示。

### 7. 最小スターターセット
- 7日分ミニマム想定の例示。
- 主食・タンパク質・汁物・味変の最低本数を提案。

### 8. よくある注意点
- 買いすぎ問題
- 同系統への偏り
- 期限確認を後回しにする癖
- 栄養の偏りへの一般的注意

### 9. CTA
- 行動ゴール：
  - 「今日の買い足しリストを作る」
  - 「まず3パターンだけ試す」
- 追従CTA（モバイル）：
  - 「スターターセットを見る」
