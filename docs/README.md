# docs README

## このdocs群の役割
このディレクトリは、LP実装前のハーネス設計資料を分離管理するための設計パッケージです。
実装コードではなく、構造・文言・視覚方針・受け入れ条件を先に固めることを目的にしています。

## 読む順番（推奨）
1. `brief.md`：目的と非目的を確認
2. `target-user.md`：誰の課題を解くか確認
3. `lp-structure.md`：全体構成を把握
4. `content-map.md`：各セクションの中身を確認
5. `component-design.md`：UI部品の責務を確認
6. `flavor-patterns.md`：食事パターンと味変の詳細
7. `stock-rotation-model.md`：運用フローを確認
8. `visual-direction.md`：デザイン判断基準を確認
9. `asset-prompt-plan.md`：素材生成の方針を確認
10. `acceptance.md`：完成判定条件を確認

## 実装フェーズへの橋渡し
次フェーズでは、以下をCodex実装依頼に含めるとスムーズです。
- 本docsを唯一の要件ソースとして参照すること
- モバイルファーストでLPを実装すること
- セクション順・注記表現・比較表の情報を維持すること
- 画像はダミーで実装し、後で差し替え可能にすること

## 実装前の最終確認
- 構成がレビュー済みか
- 文言トーン（断定回避含む）が合意済みか
- 素材方針がデザインと矛盾していないか
