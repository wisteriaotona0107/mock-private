# 02 Store Concept
## 店舗の核となる体験
「座ると、声量が自然にひとつ下がる」時間。

## 店の空気感
暗すぎない照明、木と琥珀色、必要十分な会話。

## 来店前の期待
- 初めてでも入れる
- 説教されない
- 静かに飲める

## 入店直後の印象
- 奥行きのある光
- スタッフの短い歓迎
- 価格とメニューが把握しやすい

## 滞在中の過ごし方
- 一人: 一杯＋小皿で整える
- 二人: 小声で対話
- 偶然の短い会話

## 帰るときに残る印象
「また来てもいい」が自然に残る。

## 「大人」の扱い方
年齢主義でなく、配慮・余白・節度の態度として扱う。

## NG方向
- 煽る接客
- 常連だけの閉鎖性
- 豪奢アピール過多
