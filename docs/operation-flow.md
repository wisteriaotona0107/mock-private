# Operation Flow

## Purpose
この文書は、画面設計と実装が業務フローからズレないようにするための基準文書である。

## Basic flow
1. 作業開始
2. 対象選択
3. 対象確認
4. 編集または実行
5. 保存または確定
6. 完了確認
7. 次作業へ進む
