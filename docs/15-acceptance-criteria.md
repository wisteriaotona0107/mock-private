# 15 Acceptance Criteria

- 指定ファイル構成のMarkdownが揃っている
- 実装コードを開始していない
- 「バカらしいが少し怖い」方向性が維持されている
- 5ターン制、30〜60秒、3〜5分ランが明記されている
- 横フリック主体 + タップ補助が定義されている
- インフルエンサーイベント仕様がある
- エンドレス人口指標が仕様化されている
- GPT Image向け素材一覧とプロンプト草案がある
- Swift/SwiftUI/SpriteKit比較がある
- 表現リスク配慮がある
- Mermaid図が含まれる
- 後続フェーズで実装依頼しやすい構造
