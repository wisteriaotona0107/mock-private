# NPC Target System

## NPC Attribute Model
- Appearance style
- Role/job
- Hat preferences and resistance
- Reaction type
- Score multiplier
- City-theme contribution
- Final-eval contribution

## Example NPC Pool
疲れた会社員 / インフルエンサー / 観光客 / ラーメン屋店主 / 王様志望 / 帽子拒否おじさん / 帽子審査官 / 本物の王族 / 道化師 / 学生 / 工事のおじさん / 商店街の店主

## High-Difficulty Targets
- Hat Inspector: evaluates build consistency.
- Hat-Rejecting Uncle: blocks standard approaches.
- Mega Influencer: huge upside, harsh fail penalty.

## Spawn Philosophy
- Maintain 1–5 targets per turn.
- Avoid random spam; prioritize readable strategic choices.
