# test-strategy.md

## 1. 目的
公開側静的サイトの品質確認として、JSON不備、画像欠損、iPad表示崩れを重点確認します。

## 2. テスト観点
- JSON読み込み成功/失敗
- 一覧表示と詳細導線
- ローディング/エラー/空状態
- `visible=false` 非表示
- 画像フォールバック
- iPad幅(768, 820, 1024)でのレイアウト
- console error の有無
- JSON由来文字列の安全描画

## 3. 手動テスト項目
| No | 観点 | 操作 | 期待結果 |
|---|---|---|---|
| 1 | JSON失敗 | `products.json` を404化 | エラー表示 |
| 2 | 0件 | `items: []` | 空状態表示 |
| 3 | 画像欠損 | 不正画像パス | フォールバック表示 |
| 4 | iPad幅 | 768/820/1024px | 2〜3カラムで崩れない |
| 5 | console | 各画面を操作 | 致命的errorなし |
| 6 | visible | `visible:false` を含める | 表示されない |
| 7 | 安全表示 | 特殊文字データ投入 | テキストとして表示 |

## 4. 異常系確認方法
- 取得失敗: ファイル名変更で404
- 形式異常: `items` を配列以外へ変更
- パース失敗: JSON記法を破壊

## 5. 完了条件
- JSON読み込み失敗時にUIエラー表示
- 商品0件時のUI表示
- 画像欠損時のフォールバック
- iPad幅で表示崩れが軽微
- console error が出ない
- `visible=false` が表示されない
- 商品名/説明/価格が安全描画される
