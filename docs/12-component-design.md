# 12 Component Design

対象: Header, Hero, ConceptBlock, SectionTitle, ImageTextBlock, DrinkCard, FoodCard, SeasonalMenuCard, SpaceGallery, FAQAccordion, AccessBlock, CTAButton, Footer。

各コンポーネントで以下を定義: 役割 / Props案 / PC表示 / モバイル表示 / 更新可能性 / 注意点。

例: CTAButton Props `{label, href, variant, size}`、モバイルでは横幅100%。
