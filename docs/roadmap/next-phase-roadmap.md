# Next Phase Roadmap

## Short Term: This Branch
今回のブランチで整えること:

- リポジトリの現在地を文書化する
- platform 化の意図を定義する
- 目標状態と移行手順を示す
- Codex運用と複数ロール運用の基礎資料を置く
- READMEに入口導線をつける

## Medium Term: Codex-Centered Development System
Codex中心で回る開発体制として、中期で目指すこと:

- 新規作業時に参照すべき文書を固定化する
- 小修正・設計変更・新機能でフローを使い分ける
- 変更に伴う文書更新を習慣化する
- decision memo を継続追加する
- 実装の置き場所と共通化判断を安定させる

## Long Term: Harness-like Operation / External Showcase / Super App Readiness
長期で目指すこと:

- 複数ロールのAI/人間連携を回す
- アーキテクト、実装、レビュー、文書化の受け渡しを標準化する
- 複数プロダクトまたは機能群を共通基盤上に整理する
- 外部提示に耐える構造説明とデモ導線を用意する
- 将来的なスーパーアプリ接続/統合体験を見据えた構造へ発展させる

1. 実アプリ/サービス候補の棚卸し
