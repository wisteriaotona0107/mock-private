# target-user.md

## 想定ユーザー像（一次ターゲット）

### 1) 単身者
- 冷蔵庫・収納スペースが限られる。
- 食事準備の手間を最小化したい。
- 備蓄に興味はあるが、何をどこまで持つべきか曖昧。

### 2) 忙しい社会人
- 平日夜に調理体力が残りにくい。
- 買い物頻度が低く、まとめ買いの管理が課題。
- 「時短」と「栄養の最低限確保」を両立したい。

### 3) 防災を始めたいが続かない人
- 防災用品を買って満足し、期限切れを起こしやすい。
- 非常食を特別扱いしすぎて日常で消費しない。
- 実生活に組み込める運用ルールを求めている。

### 4) 炊飯器をあまり使わない人
- 自炊頻度が低く、米を炊く習慣がない。
- 主食不足時の代替導線としてパックご飯を使いたい。
- 1食単位で管理できる主食を好む。

### 5) 体調や疲労で調理が面倒になる人
- 疲労時に火を使う調理を避けたい。
- 食欲が弱い日でも食べやすい選択肢が欲しい。
- 「最低限食べる」ための再現性ある組み合わせを求める。

## ユーザー課題（共通）
- 何を備蓄すればいいか分からない。
- 賞味期限管理が面倒で続かない。
- 同じ味で飽きる。
- 日常と防災で別管理になる。

## 提供すべき解決体験
- まずは最小構成で始められる。
- 6つの食事パターンから自分向けを選べる。
- 味変レイヤーで飽きにくくできる。
- 期限管理が運用フローとして理解できる。
