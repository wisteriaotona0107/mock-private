# Design Agent ドキュメント

## ミッション
日本酒カード印刷ページの視認性・上質感・印刷安定性を担保する。

## デザイン原則
- 和モダン
- 上質
- ミニマル
- 飲食店現場での即時判読性
- チラシとして掲示しても成立する大判ビジュアル

## タイポグラフィ方針
- 銘柄名: 太め・大きめ（主見出し）
- 価格: 強い視認性（太字・強調色）
- 説明: 可読性を優先した中サイズ
- ID: 補助情報として控えめ

## 余白設計
- A4を活かした広い余白で高級感を演出
- 画像、見出し、説明、価格、QRのブロック間に明確な間隔を持たせる
- 情報密度を抑え、チラシ用途でも読みやすくする

## レイアウト方針
- 1ページに1カード（大判）
- 上段: 大きな画像エリア
- 中段: 銘柄名と説明
- 下段: 左に価格、右に ID + QR枠
- 角丸を使わない直線的なカード外形

## QR枠の設計
- 右下に QRコード用の正方形枠を配置
- 初期状態は `QR` テキストのプレースホルダー表示
- チラシ掲示時も視認できるよう最低限のサイズを確保

## 印刷安定化
- `@page` で A4 縦を指定
- 1ページ1カードの固定レイアウトで印刷崩れを抑制
- 印刷時は不要UIを非表示

## 破綻回避
- 銘柄名は長文でも改行可能にする
- 説明文は行間と最大幅を調整し、読みやすさを保つ
- 画像は `object-fit: cover` で安定表示

## 切り取り配慮
- カード外形は角丸を使わない
- 罫線を明確にし、裁断しやすい構成を維持する
