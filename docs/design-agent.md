# Design Agent ドキュメント

## ミッション
日本酒カード印刷ページの視認性・上質感・印刷安定性を担保する。

## デザイン原則
- 和モダン
- 上質
- ミニマル
- 飲食店現場での即時判読性

## タイポグラフィ方針
- 銘柄名: 太め・大きめ
- 価格: 最も視認性を高く（太字・強調色）
- 説明: 小さめ・行間広め
- ID: 補助情報として控えめ

## 余白設計
- カード全体に十分な内側余白を持たせる
- 画像とテキストの間隔を確保
- 文字群の詰め込みを避ける

## レイアウト方針
- 上段: 画像（固定比率）
- 中段: 銘柄名 → 説明
- 下段: 左に価格、右に ID + QR枠
- 1ページは 2列×3行のグリッドで固定

## QR枠の設計
- 各カード右下に QRコード用の正方形枠を配置する
- 初期状態は `QR` テキストのプレースホルダー表示
- 価格情報より視線優先度を下げ、補助要素として扱う

## 印刷安定化
- `@page` で A4 縦を指定
- `break-after: page` によりページ分割を明示
- 印刷時は不要UIを非表示
- 空カードを含めて1ページ6枚を維持

## 破綻回避
- 銘柄名は長文でも改行可能にする
- 説明文は最大行数を制御し、オーバーフローを抑制
- 画像は `object-fit: cover` で安定表示

## 切り取り配慮
- カード外形は角丸を使わない
- 罫線は明確にして、ハサミや裁断機で切り取りしやすくする
