# Turn Design

## Fixed Run Length
- Turn 1: onboarding and baseline patterns.
- Turn 2: build direction appears.
- Turn 3: special hats/city effects start to matter strongly.
- Turn 4: optimization turn.
- Turn 5: final challenge + evaluation leverage.

## Per-Turn Envelope
- Target count: 1–5 NPCs.
- Action budget: time-limited or throw-limited (implementation choice later).
- Output: turn score, combo status, city-theme delta, buff selection.

## Fail/Recovery
- Misses reduce combo and/or consume action opportunity.
- Buff choices should allow recovery path (stability options).
