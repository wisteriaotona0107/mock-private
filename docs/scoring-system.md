# Scoring System

## Layer 1: Immediate Score
- Hit success
- Hat-NPC compatibility
- Timing quality (including just flick)
- NPC-specific bonus

## Layer 2: Build Score
- City-theme alignment
- Hat family synergy
- Success chains / combo persistence
- Multi-turn consistency

## Layer 3: Final Evaluation (Turn 5 end)
Axes:
- Fashion level
- Food culture
- Kingdom mood
- Tourism buzz
- Stability
- Chaos
- Hat diversity
- High-difficulty target clears

## Readability Rule
Every large score jump must be explainable in UI text.
