# Brief

## Title
**帽子を投げて、街を変える！**

## Goal
Create a short-session, one-handed iOS portrait game where players flick hats upward onto 1–5 NPCs per turn, shaping score, city mood, and build outcome across 5 turns.

## Core Promise
- Easy to understand in seconds.
- Satisfying flick-and-hit feel.
- Strategic choices through hat effects, target order, and buffs.
- Silly and cheerful surface with robust underlying systems.

## Scope of This Document Set
This repo phase defines harness docs only (no production Swift implementation yet).
