# brief.md

## LPの目的
- 「パックご飯を軸にしたローリングストック」の全体像を、初見でも直感的に理解できる形で提示する。
- 日常の食事運用と備蓄運用を分断せず、1つの生活導線として見せる。
- 実装前に、情報設計・文言設計・素材設計の前提を関係者間で合意する。

## 伝える価値
- パックご飯は主食ベースとして汎用性が高く、組み合わせで食事の幅が広がる。
- ローリングストックは「買う・食べる・補充する」を回すことで、無理なく継続できる。
- 味変レイヤー（香り・辛味・食感・酸味）を使うことで、備蓄食の飽き対策が可能になる。
- 疲労時・防災時・日常時で構成を使い分けると、実用性が上がる。

## 想定される成果物
- LPの骨格（セクション構成、導線、CTA設計）
- セクション別の文言・図解・表・カード仕様
- 画像素材の制作方針（後工程の生成プロンプト計画）
- 実装前レビューの受け入れ条件

## 非目的
- 特定商品のランキング化・比較レビュー
- 医療的効果や栄養効果の断定
- 災害サバイバル情報の専門解説サイト化
- 本フェーズでのHTML/CSS/JS実装
