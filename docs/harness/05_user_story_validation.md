# 05 ユーザーストーリー検証

## ユーザーストーリー
- US-001: 作業者として、1回の撮影で製品IDと重量を同時取得したい。なぜなら転記ミスと作業時間を減らしたいから。
- US-002: 作業者として、認識失敗時にその場で補正して保存したい。なぜなら再撮影を減らしたいから。

## 受入シナリオ
### US-001
1. 撮影画面を開く
2. テンプレートを選択する
3. QRと重量領域が表示される
4. 認識後、QR値/製品名/重量/単位/信頼度が表示される
5. 確認画面を経由して保存できる

### US-002
1. 認識結果に「不明」が含まれる
2. 確認画面で手入力補正する
3. 保存し、JSONログに補正後値が反映される

## 完了判定
- US-001, US-002 のシナリオがE2Eで通る
- ログから再現可能な `rawJson` が保存される
