# 00 要件定義（Requirements）

## 目的
1回の撮影・プレビューで以下を同時達成する。
- QRコードから製品IDを取得
- デジタルスケール表示から重量値（小数1桁）を取得

## スコープ
- iOS / Swift / SwiftUI
- `AVCaptureSession` によるカメラプレビュー
- QR認識（Vision または AVFoundation metadata output）
- 重量認識はモック実装（将来差し替え可能）
- GPT API連携なし（JSONログ出力のみ）

## 非スコープ
- 本番精度の7セグOCR
- クラウド連携
- バックエンドAPI

## 機能要件
- FR-001: カメラプレビュー表示
- FR-002: QR領域・重量領域オーバーレイ表示
- FR-003: レイアウトテンプレート（A/B/C）選択
- FR-004: QR認識結果の表示（QR値、製品情報、信頼度）
- FR-005: 重量認識結果の表示（重量、単位、信頼度）
- FR-006: 重量値を小数1桁へ正規化
- FR-007: 認識不能時「不明」表示 + 手入力補正
- FR-008: 保存前確認画面を必須化
- FR-009: JSONログ保存

## 非機能要件
- NFR-001: QR処理と重量処理の疎結合
- NFR-002: OCRサービス差し替え可能（Protocol）
- NFR-003: デバッグ表示（ROI枠と現在認識値）
- NFR-004: 単一撮影フローでUI遷移完結

## 受入条件（高レベル）
- AC-001: ユーザーが1画面でQR・重量の両結果を確認できる
- AC-002: 確認画面で補正して保存できる
- AC-003: 保存結果に `ScanResult` と `rawJson` が含まれる

## Human Review Gate #1（要件レビュー）
- レビュー観点:
  - 要件の漏れ・曖昧さ
  - 業務用語（製品ID、重量単位）の整合
  - MVP範囲妥当性
- 承認条件:
  - FR/NFR/AC に重大な欠落なし
  - モック実装方針の合意
