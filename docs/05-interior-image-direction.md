# 05 Interior Image Direction

## 空間テーマ
**「夜の途中にある、前へ戻るための停泊地点」**

forward/front のニュアンスは、言葉で説明せず、空間の奥行きと視線流れで表現する。

## 照明
- 暗すぎない暖色照明（手元の視認性を確保）。
- 光源は点在ではなく、手前→奥へ弱く連なる設計。
- 遠景にやわらかいぼけ光を置き、「先に続く」感覚を作る。

## 色
- 主色: 琥珀 / 深茶 / 墨黒 / くすみ金
- 補色: 低彩度のオリーブ、スモーキーグレー
- NG: 紫ネオン優勢、金属光沢過多、青白い未来感

## 素材
- 木（オーク/ウォルナット系）
- 真鍮や古びた金属の控えめな反射
- 布・革のマット質感
- ガラスは“透明感”より“温度感”重視

## 席配置
### カウンター
- 奥へ伸びる一本線を主軸にする。
- 端まで見通せるが、圧迫しない幅。
- 手前に余白、少し先に空席を置く（途中地点の象徴）。

### テーブル
- 小テーブルを点在させ、会話が漏れすぎない距離。
- 「滞在中」を感じる半端な配置（整列しすぎない）。

### 通路
- 一本道/ゆるい奥行きラインを確保。
- 入り口から奥へ視線が自然に流れる構図。

## 物体要素
- グラス: 過度な装飾なし、液面反射を静かに拾う。
- 酒瓶: ラベル誇示より、棚のリズムと深度。
- フード: 小皿中心、食べ進める“途中感”が出る量感。

## 音
- 低音量、テンポは遅め〜中庸。
- 歌詞主張の強い曲を避け、会話を邪魔しない。

## 人の距離感
- スタッフは近すぎず遠すぎず。
- 一人客への過干渉を避け、必要時に短く応答。
- 二人客の会話に“空白”が許される密度。

## 写真に写すべきもの
- 奥へ続くカウンター
- 手前から奥へ流れる照明
- 少し先の空席
- 一人客の背中（顔を主役にしない）
- 木目、グラス反射、静かな手元
- 扉の先や遠景の暖色気配

## 写真に写しすぎないもの
- 顔アップ
- 大人数の賑わい
- 乾杯演出
- 高級ホテル風の過剰装飾
- AI的な過発光・煙演出
