# Acceptance Criteria

## A. Design Document Acceptance
- Game objective is explicit.
- 5-turn structure is explicit.
- 1–5 targets per turn rule is explicit.
- Hat effect design exists.
- NPC compatibility design exists.
- Buff/build accumulation exists.
- Final-turn evaluation exists.
- UI screen list exists.
- Asset list/plan exists.
- GPT Image prompt set exists.
- Implementation phase split exists.

## B. Future MVP Acceptance
- Player can flick hat upward.
- Player can hat 1–5 NPC targets.
- Hit/compatibility/score feedback shown.
- Buff is selectable after turns.
- Final evaluation appears after turn 5.
