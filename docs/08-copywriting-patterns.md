# 08 Copywriting Patterns

## 基本トーン
- 静か、短い、余白がある。
- 「励ます」のではなく「受け止める」。
- 成功哲学・自己啓発・勝ち負け語彙を排除。

## メインキャッチコピー 10案（forward / waypoint優先）
1. 少し先へ、もう一杯。
2. 夜を終える前に。
3. 明日へ戻る途中。
4. 続いていく人のための場所。
5. 立ち止まるための前進。
6. 急がなくていい。
7. 少し進めば、それでいい。
8. 今日の続きへ。
9. 夜の速度で。
10. 続けるための一杯。

## サブコピー 10案
1. 声を張らずにいられる、夜の中継地点。
2. 一人でも、二人でも、歩幅を戻せる席。
3. 今日を閉じて、明日に返すための時間。
4. 会話がなくても、居づらくない。
5. 知識より、気分で選べる一杯を。
6. ふらっと寄って、静かに整う。
7. 奥へ続く光の先で、少し休む。
8. 途中で立ち寄ることが、続ける力になる。
9. 夜の余白を、ここに置いていく。
10. 無理をしない大人のための小さな停泊地。

## コンセプト本文 3案
### A案
otona.to.w は、夜を“頑張る”場所ではありません。  
今日を終える途中で、少し座って、呼吸を戻すための場所です。  
一人でいてもよく、二人で話しても静かでいられる。  
酒は主役でありながら、空間の一部でもある。  
明日へ戻る前に、歩幅を整えるための一杯を。

### B案
前へ進むことを急がない夜があります。  
otona.to.w は、その途中にある中継地点。  
奥へ続くカウンター、琥珀の光、小さな会話。  
ここで過ごす時間は、何かを達成するためではなく、続けるためにあります。

### C案
立ち止まることは、後退ではない。  
この店は、続いていく日々のあいだにある“前進の余白”です。  
一杯だけでも、少し長くても。  
急がない夜の速度で、あなたの明日に戻ってください。

## 一人客向けコピー 5案
1. 一杯だけでも、気兼ねなく。
2. 話さない夜にも、席があります。
3. 背筋をゆるめるためのカウンターへ。
4. 帰る前に、少しだけ整える。
5. 何もしない時間を、遠慮なく。

## 二人客向けコピー 5案
1. 小さな声で、長く話せる。
2. 相談ごとも、近況も、静かなままで。
3. 会話の間に、いい沈黙がある。
4. 夜を急がない二人のために。
5. 一杯ごとに、温度がほどける。

## 初回来店者向けコピー 5案
1. 初めての方へ。まずはおすすめから。
2. 詳しくなくても、気分から選べます。
3. 予約なしでも、空席があればご案内します。
4. 服装に決まりはありません。普段のままで。
5. 一人でのご来店も多い店です。

## メニュー更新用コピー 5案
1. 今夜の季節の一杯、更新しました。
2. 夜の途中に合う小皿を追加しました。
3. 今週のおすすめ、静かに入れ替えています。
4. いまの気分に寄り添う新しい一杯。
5. 帰る前にちょうどいい、今月のおすすめ。

## 予約導線用コピー 5案
1. 今夜の席を確認する
2. 立ち寄り前に空席を見る
3. 一人席・二人席のご相談はこちら
4. ご来店時間をゆるく予約する
5. 明日へ戻る前の席を確保する

## 避ける方向（禁止）
- 成功哲学、自己啓発、ビジネス成長訴求
- 「挑戦」「勝つ」「上へ行く」等の上昇圧コピー
- 露骨なアダルト表現
- 過度な高級店語彙 / 安売り語彙 / 映え語彙
