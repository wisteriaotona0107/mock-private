# Screen List

## 1. Main Gameplay Screen
Must include:
- Turn index
- Remaining time/actions
- Score + multiplier
- Current city theme status
- 1–5 NPC targets
- Hat selection tray/cards
- Flick trajectory feedback
- Hit/reaction popups

## 2. Turn Result Screen
Must include:
- Turn summary
- Hats used
- NPC-by-NPC results
- City theme changes
- Next-turn implications
- 3-choice buff selection

## 3. Final Evaluation Screen
Must include:
- Final score
- Build profile summary
- Title/rank
- Success/failure factors
- Replay CTA
