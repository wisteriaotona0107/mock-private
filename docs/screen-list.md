# screen-list

## 主要画面一覧
- **ログイン/利用者確認画面**：利用者と利用拠点を確認し、操作責任の起点を明示する。
- **案件一覧画面**：担当案件を状態・期限順に確認し、優先対応対象を選択する。
- **案件詳細画面**：案件の基本情報、進捗、履歴を統合表示し、判断材料を揃える。
- **作業更新画面**：進捗状態・メモ・次アクションを記録し、最新状況を反映する。
- **承認待ち一覧画面**：確認・承認が必要な項目を抽出し、滞留を可視化する。
- **通知/差戻し画面**：差戻し理由や対応依頼を時系列で把握し、再対応に繋げる。
- **設定・マスタ参照画面**：拠点、担当、状態定義など運用前提の参照情報を確認する。

## 画面遷移（最低限）
- ログイン/利用者確認 → 案件一覧
- 案件一覧 → 案件詳細
- 案件詳細 → 作業更新
- 作業更新 → 案件詳細（更新結果反映）
- 案件一覧 → 承認待ち一覧
- 承認待ち一覧 → 案件詳細
- 案件詳細 → 通知/差戻し
- 案件一覧 または 設定・マスタ参照 へ戻る導線を常設

## 補足方針
- 一覧から詳細への遷移は常に同じ操作位置で提供し、学習コストを下げる。
- 更新系画面は確認系画面と明確に見た目を分け、誤編集を防ぐ。
- 主要遷移は2〜3タップ以内で完結し、デモ中の説明停滞を防ぐ。
