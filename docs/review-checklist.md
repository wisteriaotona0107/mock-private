# Review Checklist

- Is input interaction intuitive?
- Does hat-throwing feel satisfying?
- Is target count constrained (not too many)?
- Are meaningful strategic decisions present?
- Are hat differences mechanically clear?
- Is buff accumulation felt across turns?
- Is there clear purpose toward turn-5 climax?
- Is UI readable at mobile size?
- Is asset replacement pipeline practical?
- Is JSON-driven migration straightforward?
- Is world tone non-aggressive and safe?
- Does silliness coexist with playability?
