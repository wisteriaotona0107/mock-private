# Decision 0001: 静的ドキュメントモックサイトを採用する

## Context

README と AGENTS.md の内容確認を、テキストだけでなくブラウザ上でも行いたい要求がある一方で、現時点では本格的なフレームワーク導入よりも最小構成を維持したい段階です。

## Decision

ルート直下に `index.html` / `styles.css` / `script.js` を置く静的サイトを採用し、ドキュメント導線と運用原則を視覚的に確認できるようにします。

## Consequences

- 依存関係なしで即座に起動・確認できます。
- 将来フレームワーク化する場合の前段として、必要な情報設計を先に検証できます。
- 画面表現は実装できますが、現時点ではドキュメント案内が主目的です。
