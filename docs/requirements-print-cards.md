# 要件定義: 日本酒提供カード印刷ページ

## 1. 目的
飲食店で使用する日本酒提供カードを、A4用紙へ安定して印刷できるページを提供する。

## 2. 用途
- 卓上カード
- 商品紹介カード
- 日本酒提供カード
- 掲示用チラシ

## 3. 印刷仕様
- 用紙: A4
- 向き: 縦
- 1ページあたり: 1枚（大判カード）
- レイアウト: 1カード固定

## 4. データモデル
`data/sake-list.json` は配列形式とし、以下の項目のみを使用する。
- `id`
- `name`
- `desc`
- `img`
- `price`

追加項目は使用しない。

## 5. カード構成
表示順・優先順位:
1. 画像
2. 銘柄名
3. 価格
4. 説明

カード下部に `PRICE` と `ID` を配置する。

### 5.1 QRコード枠
- 各カードに QRコードを配置できる専用枠を追加する。
- 初期状態はプレースホルダー（`QR` 表示）でよい。
- データモデルに項目追加は行わない（既存の5項目のみ使用）。

## 6. 画面モード
表示してよい要素:
- タイトル
- 説明
- 印刷ボタン

## 7. 印刷モード
以下を非表示:
- 説明
- UI
- ボタン

## 8. JavaScript責務
- JSON読み込み
- ページ分割
- カード生成
- フォールバック処理
- 印刷

必須関数:
- `chunkItems()`
- `formatPrice()`
- `createCard()`
- `createEmptyCard()`
- `renderPages()`
- `loadItems()`

## 9. ページ分割
- 1ページ: 1件
- 例: 12件 = 12ページ

## 10. フォールバック
`data/sake-list.json` 読み込み失敗時は、JS内のフォールバックデータを使用する。

## 11. CSS要件
- CSS Grid を使用
- `@page` を使用
- `@media print` を使用
- 長い銘柄名でも破綻しない
- 画像比率固定
- 印刷崩れしない
- カード外形は角丸を使わず、切り取りしやすい角ばったデザインにする
