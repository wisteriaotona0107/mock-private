# flavor-patterns.md

## 6系統の食事パターン

### 1. 丼化系（満足度重視）
- 例：牛丼レトルト、親子丼レトルト、麻婆豆腐、中華丼、カレー
- 味変：七味、ラー油、山椒、ごま油、フライドオニオン

### 2. 卵系（低コスト・高回転）
- 例：卵かけご飯、納豆＋卵、温玉＋めんつゆ、卵雑炊
- 味変：海苔、鰹節、バター醤油、コチュジャン、粉チーズ、黒胡椒

### 3. 缶詰系（ローリングストック主力）
- 例：サバ缶、ツナ缶、焼き鳥缶、コンビーフ、いわし味噌煮
- 味変：生姜、ネギ、オリーブオイル、マヨネーズ、柚子胡椒

### 4. ふりかけ・混ぜ込み系（最軽量運用）
- 例：ゆかり、のりたま、鮭ふりかけ、混ぜ込みわかめ、お茶漬け
- 味変：ごま油、バター、刻み海苔、わさび

### 5. 冷凍食品系（日常満足度UP）
- 例：唐揚げ、餃子、ハンバーグ、シュウマイ
- 味変：レモン、タルタル、柚子胡椒、ブラックペッパー

### 6. 汁物投入系（疲労時・体調不良時に使いやすい）
- 例：味噌汁かけ、スープ雑炊、クッパ風、お茶漬け
- 味変：味噌汁＋卵、わかめスープ＋ごま油、コーンスープ＋黒胡椒、豚汁＋七味

## 味変レイヤー整理

| 食感 | フライドオニオン、揚げ玉、刻み海苔 |
| 酸味 | ポン酢、レモン、梅、酢 |
