# Hat System

## Role of Hats
Hats are functional gameplay cards/equipment with score and systemic effects.

## Categories
- Normal hats: cap, straw hat, knit cap, hunting cap, silk hat.
- Special hats: crown, chef hat, construction helmet, silk hat variant, rare/random hats.

## Hat Data Responsibilities
Each hat should define:
- Base score profile.
- Preferred/disliked NPC tags.
- City theme influence vector.
- Optional special effect hook.
- Asset linkage.

## Design Principles
- Visual silhouette must communicate function quickly.
- No hat is cosmetic-only.
- Rare hats may add risk/reward variance.
