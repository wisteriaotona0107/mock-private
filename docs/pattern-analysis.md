# パターン分析表

## Pattern 01 王道セールス型
1. UI構造: ヒーロー→3こだわり→コース→CTA帯→利用シーン
2. 情報階層: 予約CTA最上位、次にコース価格、最後に補足
3. CTA戦略: 各セクション末尾に予約ボタンを反復
4. 色温度: 明るい緑+白+黄
5. 写真比率: 45%
6. カード密度: 中
7. 余白特性: 十分な余白で読みやすい
8. フォント方向性: 可読性重視ゴシック
9. 危険箇所: 過剰ミニマル化/SaaS化
10. 禁止事項: 黒背景化・高級化

## Pattern 02 肉料理ビジュアル訴求型
1. UI構造: ダークヒーロー→肉カード群→ビールペアリング→ギャラリー→CTA
2. 情報階層: 写真主役、テキスト短く強く
3. CTA戦略: ヒーローと最下部の2点集中
4. 色温度: 暖色×黒の夜感
5. 写真比率: 70%
6. カード密度: 高
7. 余白特性: 狭め
8. フォント方向性: 太め見出し＋明朝アクセント
9. 危険箇所: 発光演出のやりすぎ
10. 禁止事項: 白ベース化・余白増やしすぎ

## Pattern 03 サーバー体験型
1. UI構造: サーバーヒーロー→ラインナップカード→体験ポイント→肉ペアリング→CTA
2. 情報階層: サーバー訴求最上位、体験価値次点
3. CTA戦略: サーバー体験予約を主CTAとして反復
4. 色温度: 明るめ白背景+琥珀色アクセント
5. 写真比率: 55%
6. カード密度: 中高
7. 余白特性: パネルごとに明瞭
8. フォント方向性: ゴシック中心
9. 危険箇所: 肉主体化・黒背景化
10. 禁止事項: 高級ステーキ店風の演出
