# content-map.md

## 目的
LP各セクションに配置する要素（文言、表、カード、図解）を定義し、実装前レビューを可能にする。

## セクション別マップ

| セクション | 主文言要素 | UI要素 | 図解/表 | 備考 |
|---|---|---|---|---|
| Hero | タイトル、サブ、CTA | ヒーロー、ボタン2種 | 背景イメージ | 日常感重視 |
| 軸にする理由 | コア式説明 | インフォカード | 構造図 | 「白いベース」概念 |
| 賞味期限と考え方 | 期限目安説明、注記 | 比較表、注意書き | 期限タイムライン | 断定回避 |
| 6つの食事パターン | 各系統の説明 | パターンカード群 | カテゴリマップ | 一覧性優先 |
| 味変レイヤー | 4レイヤー説明 | レイヤーカード | マトリクス図 | 飽き対策訴求 |
| シーン別構成 | 3運用の特徴 | セットカード | 3列比較表 | 選びやすさ |
| 最小スターター | 7日分例 | チェックリストカード | 構成比ミニ図 | 購買導線 |
| 注意点 | 失敗例と回避 | アラートボックス | なし | 過度な不安訴求NG |
| CTA | 行動喚起 | CTAボックス | なし | 次行動を明示 |

| 種類 | 賞味期限目安 | 用途 |
|---|---|---|
| パックご飯 | 約6か月〜1年 | 日常備蓄・疲労時・ローリングストックの軸 |
| アルファ化米 | 約5年 | 非常食・長期保存 |
| カップ飯 | 約5〜6か月 | 手軽な満足飯 |
| 缶詰 | 約2〜5年 | タンパク質補強・停電時にも強い |
| レトルト食品 | 約1〜2年 | ご飯との組み合わせ主力 |
| フリーズドライ味噌汁 | 約1〜2年 | 汁物・温度感・疲労時 |
| プロテインバー / ナッツ | 約6か月〜2年 | 補助食・非常時 |

## 情報階層ルール
1. 見出しは「結論先出し」。
2. 1セクション1メッセージを原則化。
3. 数字情報には注記を添える。
4. モバイルで縦読みに破綻しない順序で配置する。
