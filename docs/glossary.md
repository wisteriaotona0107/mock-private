# Glossary

## 100本ノック
短期間で多数の試作や反復を行い、探索量を増やす開発スタイル。本リポジトリでは価値ある前段とみなすが、そのままでは継続運用に向かないため、構造化対象とする。

## Platform
複数の成果物や機能を継続的に載せられる構造・共通判断軸・運用ルールの総体。

## Harness-like operation
複数の役割を持つAIまたは人間が、明確な受け渡し物と責務分離に基づいて協調する運用形態。

## Current state
今このリポジトリに実在する構造・責務・不足事項。

## Target state
将来的に目指す構造。現状と混同しないことが重要。
