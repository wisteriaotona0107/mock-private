# create_lp_pattern

以下の条件で、日本酒バーLPの1ページ構成案を作成してください。

- 参照: `docs/copy_patterns.md`, `docs/lp_structure.md`, `docs/legal_boundary.md`, `docs/priority_matrix.md`
- 指定された Pattern / ID を主軸コピーとして採用
- 「持ち込み可」は強調するが、無法感・激安感は出さない
- トーンは指示された方向性（例: 静かな余白）に合わせる
- 出力:
  1) 全体トーン要約（3行）
  2) 10セクションの見出しと本文案
  3) Rules文言（3〜5項目）
  4) Heroコピー案（3案）
  5) CTA案（2案）
  6) NG表現セルフチェック

## 入力例
「docs/copy_patterns.md の Pattern A / ID 1 を主軸にして、日本酒バーLPの1ページ構成案を作成してください。トーンは静かな余白寄り。持ち込み可は強調するが、無法感は出さないでください。」
