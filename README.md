# 2D サンドボックス・ローグライト プロトタイプ

TypeScript + Vite + Canvas で構築した最小プレイ可能サンドボックスです。チャンク生成された地形を掘削・設置しながら、インベントリと IndexedDB セーブ/ロードを試せます。

## セットアップ

```bash
npm install
```

## 開発サーバー

```bash
npm run dev
```

ブラウザで `http://localhost:5173` にアクセスするとプレイできます。

## ビルド

```bash
npm run build
```

`dist/` に本番ビルドが出力されます。`npm run preview` で生成物を確認できます。

## 操作説明

| 入力 | アクション |
| --- | --- |
| W / ↑ / Space | ジャンプ |
| A / ← | 左に移動 |
| D / → | 右に移動 |
| 左クリック | ポインタ下のブロックを破壊し、インベントリへ追加 |
| 右クリック | 選択中ホットバータイルを設置 |
| 1〜9 | ホットバー選択 |
| Esc | ポーズメニュー表示（Save / Load / Reset World） |

## システム概要

- 64×64 タイルのチャンクを周囲のみ生成し、カメラの可視範囲に合わせて描画します。
- 標高ノイズと木の簡易デコレーションにより地形を生成。
- プレイヤーは AABB 物理＋重力で移動し、タイル衝突を解決します。
- インベントリは 9 スロット構成でスタック上限は 999。破壊したタイルは直接加算されます。
- 5 秒ごとの自動セーブとポーズメニューからの手動セーブ／ロード／リセットに対応。保存先は IndexedDB。
- 画面左上に FPS、現在チャンク座標、使用シードを表示します。

## 注意

初回ロード時に保存データが存在すれば自動で読み込みます。保存済みのシードと異なるビルドをロードしたい場合は、ポーズメニューの Reset World を使用してデータをクリアしてください。
