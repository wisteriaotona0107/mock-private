# Tarot Gacha Web Mock

このリポジトリは、タロットカードのスプレッド型ガチャ体験を再現したハイファイ・モックのドキュメントと、デザイン仕様に基づく静的Webアプリケーションのサンプル実装を収録しています。

## 構成
- `design/tarot-gacha-mock/` デザイン仕様ドキュメント
- `web/` レスポンシブなデモWebアプリケーション（HTML/CSS/JS）

## 使い方
1. 任意の静的ホスティングで `web/` ディレクトリを公開するか、ブラウザで `web/index.html` を開きます。
2. 左側のナビゲーションから各画面（トップ、バナー詳細、ガチャ演出、リザルト、図鑑、マイページ、管理、コンポーネント、ステート）に切り替えて閲覧できます。
3. ガチャ演出画面ではカードをクリックすると表裏が反転し、デザイン上のインタラクションを体験できます。
