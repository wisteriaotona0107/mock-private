# 小規模店舗向けPOSレジ

ブラウザのみで動作する小規模店舗向けの簡易POSレジシステムです。商品管理、会計処理、売上履歴の確認を一画面で行えます。データはブラウザのローカルストレージに保存されるため、導入が容易で小規模店舗のバックヤード端末やタブレットでの運用を想定しています。

## 主な機能

- **商品管理**: 商品の登録・編集・削除、SKU(バーコード)検索
- **会計処理**: 商品検索からのカート投入、数量変更、税計算、釣銭計算
- **売上履歴**: 日付フィルタ、レシートビューア、印刷機能
- **設定**: 消費税率の変更と保存

## 使い方

1. `index.html` をブラウザで開きます。
2. 初回起動時はサンプル商品が登録済みです。商品管理フォームから登録内容を編集できます。
3. 会計エリアで商品を選択し、数量を入力して「カートに追加」を押します。
4. カート内容を確認し、お預かり金額を入力して「会計確定」を押すと売上が記録されます。
5. 売上履歴は右側の一覧に表示され、任意の取引を選択するとレシートが表示されます。

## データの保存について

- 商品情報と売上履歴はブラウザのローカルストレージに保存されます。
- ブラウザのデータを削除すると内容が消去されるため、定期的にブラウザの開発者ツールなどからエクスポートしてバックアップを取ってください。

## カスタマイズ

- `styles.css` でレイアウトや色を調整できます。
- `app.js` の `getDefaultProducts()` を書き換えることで初期商品の内容を変更できます。

## 開発メモ

- 追加のビルドステップは不要です。静的ファイルを任意のHTTPサーバーで配信して利用してください。
- ブラウザは最新のChrome/Edge/Firefox/Safariを想定しています。
