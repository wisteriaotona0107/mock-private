# 坊主頭量産世界 / Harness Design

「坊主頭量産世界」は、髪型を坊主へ統一していく短時間ローグライト風アーケードゲームの設計プロジェクトです。

## このリポジトリの現在地
- 現在は**実装前のハーネス設計フェーズ**です。
- Swift/SwiftUI/SpriteKitでの実装は後続フェーズで行います。
- 本フェーズでは、ゲーム仕様・世界観・UI・データモデル・素材生成要件をMarkdownで定義します。

## 目標プレイ体験
- 通常モード: 1ラン約3〜5分
- 1ターン: 30〜60秒
- 全5ターンで最終評価
- 横フリック主体 + タップ補助の軽快操作

## ドキュメント構成
`docs/` 以下に、企画・仕様・データ構造・素材要件・実装計画を段階的に整理しています。

## 進め方
1. 仕様変更は `docs/` 先行で更新
2. データ駆動モデルを維持
3. 素材生成と実装を分離
4. 次フェーズで最小プロトタイプを実装
