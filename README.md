# 日本酒バーLP ハーネス設計資料

このリポジトリは、**「持ち込み可」を文化として表現する日本酒バーLP**を、後続チャットで安定して制作するための設計資料群です。  
実装（HTML/CSS/Reactなど）は行わず、まず要件・コピー・構成・表現境界を固定するために使います。

## 使い方（推奨フロー）

1. **`docs/copy_patterns.md` でキャッチコピーIDを選ぶ**  
   - まず High 優先度から検討し、LPの主軸コピーを1つ決めます。
2. **`prompts/create_lp_pattern.md` または派生プロンプトを使う**  
   - トーンに応じて `quiet / experimental / sakaba` を選択します。
3. **チャットでID指定してLP案を生成する**  
   - 例: 「ID 1を主軸にLPパターンを作成」
4. **生成LP案を `docs/acceptance.md` でレビューする**  
   - 文化表現・法務衛生表現・UI/CTA観点で受け入れ判定します。
5. **画像素材は `docs/gptimage_prompts.md` を使って別途生成する**  
   - Hero/Concept/Rulesなどの用途別プロンプトを活用します。
6. **LP本文・画像・実装を一気に作らず、段階的に確認する**  
   - 「設計資料固定 → LP案生成 → レビュー → 画像生成 → 実装」の順で進めます。

## ディレクトリ

- `docs/`：設計判断・表現ガイド・レビュー基準
- `prompts/`：後続チャットでLP案を生成するためのプロンプト群

## 重要方針

- 「持ち込み可」は**節約訴求**ではなく、**酒との相性を探す文化**として表現する。
- 「なんでも自由」ではなく、**空気を守る持ち寄り文化**として伝える。
- 個人店の静かな空気、店主の思想、常連文化の育ちを優先する。
