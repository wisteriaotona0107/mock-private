# Lunch Refresh

お昼休憩の効率的な休憩・睡眠方法を手軽に記録できるローカル専用のモックWebアプリです。ブラウザのローカルストレージにのみ保存されるため、サーバーやデータベースは不要です。

## 使い方
1. `index.html` をブラウザで開きます。
2. 「休憩・睡眠ログを追加」フォームから日時、カテゴリ、方法、時間、体感、メモを入力し「記録する」を押します。
3. 直近の記録や平均時間、気分スコア、人気メソッドなどの指標が自動で更新されます。
4. カテゴリ絞り込みやキーワード検索、並び替えで履歴を振り返り、不要なデータは削除または全件クリアできます。
5. 「デモデータ追加」を押すとサンプルのログを投入し、動作イメージをすぐ確認できます。

## 主な機能
- ローカルストレージへの保存・読込
- カテゴリ/キーワードでのフィルタリングと並び替え
- 直近7日間の平均休憩時間、気分スコア、人気メソッド表示
- 1件ごとの削除と全件クリア

## 開発メモ
- 追加のビルド工程は不要です。静的ファイルのみで構成されています。
- デザインには `styles.css`、振り返りロジックには `app.js` を利用しています。
