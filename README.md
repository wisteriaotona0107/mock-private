# mock-private
private mockup

## セットアップ手順

1. Node.js (v18 以降を推奨) を用意します。
2. 依存関係のインストール:

```bash
npm install
```

   ブラウザモックのバンドルは同梱の Node スクリプトで生成されます。

## モックテストの実行

このリポジトリでは、コンボ判定や高リスク博打フローを確認するためのモックテストを提供しています。

```bash
npm test
```

上記コマンドは `tests/simulation.test.js` を実行し、成功・失敗・キャンセルの各パターンを通してエンジン挙動を検証します。

## ブラウザモックの起動

配置×コンボ×一時バフの流れをブラウザで確認できる簡易 UI を用意しています。以下のコマンドでビルドまたはプレビューを行えます。

### ビルドのみ

```bash
npm run build:web
```

`dist/` に HTML/CSS/バンドル済み JavaScript が生成されます。任意の静的サーバーから配信してください。

### 監視つきビルド

```bash
npm run watch:web
```

`web/` 配下の変更を監視しながらバンドルを更新します (サーバーは起動しません)。

### ローカルサーバー付きプレビュー

```bash
npm run dev:web
```

`http://localhost:8000` でモック UI を閲覧できます。テーマ選択、素材方向の設定、ブロック配置、高コンボ博打の挙動、演出ログなどをリアルタイムに確認できます。

### UI の見どころ

- テーマとキャンセル挙動の切り替えで周回状態を即リセット
- 素材方向性の指定/解除に応じたバフ付与挙動の追跡
- ブロック配置時のコンボ継続・断絶、報酬、バフ消費を可視化
- 小/大演出や完全博打のログを専用パネルで確認
