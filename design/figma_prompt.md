# Figma プロンプト（日本酒バー「霧島」）

1. **テーマ/キーワード**: 「日本酒」「木の温もり」「和紙の柔らかさ」「夜のほの暗さ」「余白と整列」。
2. **レイアウト**:
   - 1440px アートボード。12カラム/80pxガター/160pxマージン。
   - ヒーロー: フルブリード背景 + 黒グラデ + 縦長の酒瓶シルエット。
   - セクション: 日本酒カードグリッド、ペアリングリスト、ニュースカード、ギャラリー Masonry、予約フォーム。
3. **カラー**（HEX）: 背景 #0f0d0a、カード #181512、アクセント#b97f2a、ハイライト#e7c48c、テキスト#f4f1e8、和紙#f6f1e0。
4. **タイポ**: 日本語は「Noto Sans JP」Regular/Medium/Bold。英字アクセントは「Playfair Display」Italicを見出しに少量使用。
5. **コンポーネント**:
   - Navbar（ロゴ左・右に CTA）。
   - Sake Card（画像・タグ・名称・蔵元/都道府県・テイスティング・提供温度）。
   - Menu Chip（カテゴリー・料理名・価格）。
   - News Card（公開日・タイトル・タグ）。
   - Reservation Form（名前/日付/時間/人数/要望）。
6. **スタイルガイド**: ドロップシャドウは 0 20 60 rgba(0,0,0,0.35)。角丸 12-16px。余白は 8の倍数で設計。
7. **注記**: 画像は Unsplash の酒器/木目サンプル URL を仮配置。最終納品時に店舗撮影写真へ差し替え。
8. **出力**: デスクトップ1枚 + モバイル（390px）1枚。オートレイアウトで再利用可能なコンポーネント化。
