# Tarot Gacha Web App High-Fidelity Mock Spec

本ドキュメントは、タロットカードスプレッドを用いた「Tarot Gacha」Webアプリのハイファイ・モックを実装志向で定義したものです。1440×900デスクトップ、390×844モバイルのフレームを対象とし、Atomic Designの粒度でコンポーネントを整理しています。

## 1. ブランド & トーン
- **世界観キーワード**: mystic ui / velvet felt surface / gold foil accents / subtle grain texture / tarot spread layout / elegant serif heading / soft elevation shadows
- **カラー**
  | 用途 | カラー | 値 |
  | --- | --- | --- |
  | プライマリベース | 深緑 | `#1B4332`
  | アクセント | ゴールド | `#D4AF37`
  | セカンダリ背景 | エクリュ | `#F4EDE4`
  | ハイライト | アクセント紫 | `#7B2CBF`
  | 黒基準 | 透過ブラック | `rgba(0,0,0,0.45)` (シャドウ)
- **背景処理**
  - ベース: 深緑フェルト調テクスチャ（4pxソフトノイズ、微細な織り模様）
  - ヴィネット: スポットライト（中心 `rgba(255,255,255,0.18)` → 外周 `rgba(0,0,0,0.55)`）
- **シャドウ**: 0 12px 24px rgba(0,0,0,0.35) を最大値、カードはZ=16dpで浮遊感
- **角丸**: グローバル 12px / カード・モーダル 16px
- **アイコン**: 1.5pxライン、等角エッジ。正位置▲、逆位置▽アイコンはゴールドライン。音想起用ベル型アイコンはアクセント紫。

## 2. タイポグラフィ
- 見出し: Marcellus (英字) + Noto Serif JP (日本語)。H1=48px/120%、H2=32px/130%、H3=24px/140%
- 本文: Noto Sans JP 18px/150%
- ラベル・数値: Noto Sans JP 16px/140%、トラッキング -2%
- 数値強調: Tabular Lining設定

## 3. レイアウトシステム
- デスクトップ: 幅1440px、12カラム、マージン80px、ガター24px。
- モバイル: 幅390px、4カラム、マージン16px、ガター16px。
- 最大コンテナ幅: 1200px。中央揃え。
- 主要CTA: デスクトップは右下固定のカード状コンテナ（幅320px、高さ120px）。モバイルは下部セーフエリアを考慮した高さ96pxのFixedバー。

グリッドアノテーションは各フレームの節に記載。

## 4. 画面モック定義
下記各セクションにデスクトップ／モバイルのビジュアル構造、余白、コンポーネント階層、トーンを記載。

### 4.1 トップ / バナー一覧
#### デスクトップ (1440×900)
- **ヘッダ (高さ96px)**
  - 背景: 深緑90%透明のガラスモーフィズムプレート。
  - 左: ロゴ（タロット紋章、円形中に星とカードシルエット）。
  - 右: ナビゲーション `図鑑`、`マイページ`（Noto Sans JP 16px / ゴールドhover）。
  - プライマリCTA: アクセント紫塗り、ラベル「バナーを見る」、内側ゴールド線3px。
- **ヒーローセクション**
  - グリッド: 左6カラムにタイトル「Tarot Gacha」（Marcellus 48px）、サブタイトル「静かな高揚を引き寄せる、運命のスプレッド」。
  - 右6カラム: 半透明カード背面(3枚)が深緑背景から浮かぶ。カード背面は金箔幾何学、オフセットX±48px、Y±32px、回転±6°。
  - CTA群: 「バナー一覧へ」(副ボタン深緑アウトライン)、「提供割合を見る」(テキストリンク)。
- **バナーグリッド**
  - 3列カード、各カード幅296px、高さ420px、カード角16px、シャドウ。
  - 内容: サムネ (カード束の写真)、上部左に期間バッジ（ゴールド背景、ラベルNoto Sans 14px）。右上「提供割合」ボタン（テキスト＋Chevron）。
  - 下部: ピティ進捗バー (ゴールド/エクリュ背景、幅100%)。バー下に残回数ラベル。
- **CTA固定パネル**
  - 右下固定 320×120px、ゴールド枠、背景深緑70%。「今すぐガチャを引く」＋正位置▲アイコン。
- **フッタ**
  - ゴールド細線で区切り。
  - 左: 確率表記「※提供割合はこちら」リンク、右: 利用規約/プライバシーリンク。

#### モバイル (390×844)
- ヘッダ高さ72px、ロゴ左、右にハンバーガーアイコン。
- ヒーロー: タイトル32px、サブ18px。背景カードは上下にスライド。
- バナーリスト: 1列、横スクロールスナップ。カード幅320px、高さ420px。ピティバーは下部固定。
- CTAバー: 下部固定、高さ96px、角丸上辺16px。右半分にゴールド塗り「ガチャを引く」、左半分に提供割合リンク。

グリッドアノテーション: カード間24px（モバイル16px）。

### 4.2 バナー詳細
#### デスクトップ
- **ヘッダ情報**: 左上にタイトル(H1)、下に開催期間（ゴールドラベル）、右にピティ残回数プログレス（幅320px、ゴールドグラデ、値ラベルTabular）。
- **提供割合リンク**: ゴールドテキスト＋アイコン。
- **スプレッド選択タブ**: 3つのラジオカード（1枚/3枚/ケルト十字）。各カード幅280px、高さ200px。
  - 選択状態: ゴールドアウトライン+内側グロー。下部にプレビューサムネ（Spread miniature PNG）。
  - プレビュー: ミニカードを半透明で表示（座標注記: 例 `(-30°, X:-40, Y:20)`）。
- **CTAボード (右下固定)**
  - 「単発」ボタン（ゴールド塗り）。「10連」ボタン（アクセント紫グラデ + ゴールド枠）。
  - 残チケット数バッジ（エクリュ背景ゴールド文字）。
- **提供割合モーダル**
  - 幅640px。レア分布: `N 60% / R 25% / SR 10% / UR 5%` を水平バーチャート。
  - 正逆比率: Upright 70% / Reversed 30%、ドーナツチャート。
  - 注釈: テキストとアイコン（i）。

#### モバイル
- ヘッダ下にピティバー全幅。
- スプレッド選択: 横スクロールタブ、各カード幅240px。
- CTA: 下部固定、単発/10連を縦2ボタン。
- 提供割合モーダル: フルスクリーン、閉じるボタン右上。

### 4.3 ガチャ演出
#### デスクトップ
- 背景: フェルト面 + 奥行きグラデーション。中央スポットライト1200px径。
- スプレッド配置: 選択スプレッドに応じた座標を記載。
  - 例: ケルト十字: 中央カード(0°)、交差(-90°)、過去(-20°)、未来(20°)、潜在(-60°)、顕在(60°)、結果(0°)、周囲(10°)、希望(-10°)、最終(0°)。
- カード裏面: 120×200px (モバイル100×160)。金箔幾何学紋様（六芒星風だが抽象）。
- パーティクル: レア度に応じたパーティクルエフェクト色。
- インタラクション: カード hover で3°傾き+パララックス。クリックでY軸回転0.6s Cubic-bezier.
- スキップ: 右上テキストボタン（Noto Sans 16px、ホバー下線）。

#### モバイル
- カードサイズ縮小、縦方向スクロールせず全体表示。タップ領域を大きく保つ（カード間隔12px）。
- スキップボタンは上部右にピルボタン。

### 4.4 リザルト
#### デスクトップ
- 左 70%幅: カードグリッド。10連=2×5。カード角16px、レア枠色: N淡金、Rゴールド、SR紫金、UR白金。
  - 各カード右上に正/逆アイコンバッジ。
  - hover時: 拡大1.05倍＋シャドウ強調。
- 右 30%幅: 詳細パネル（高さ100%）。
  - カード名（H2）＋レアバッジ。
  - 正位置/逆位置タブ: ピル切替。コンテンツ: 意味タイトル、説明本文、タグチップ（例: `#恋愛` `#転機`）。
  - シェアボタン: 深緑アウトライン+アイコン。
- 下部: セカンダリCTA「もう一度引く」「図鑑へ」（左右並び）。

#### モバイル
- グリッド: 2列。タップで詳細パネルが下からスライド。
- 詳細パネル: 半モーダル（高さ60%）。
- CTA: 下部固定2ボタン。

### 4.5 図鑑
#### デスクトップ
- フィルタバー: 上部にレアトグル（N/R/SR/UR）、タグチップ（カルーセル）、所持/未所持スイッチ。
- カード一覧: 4列。各カードにホバーエレベーション、未所持はエクリュトーンダウン。
- スケルトン: ランダムローディングカード(シャイナーアニメ)。
- 詳細モーダル: 幅720px、正/逆タブ、意味テキスト、出現バナー情報（リスト形式）。

#### モバイル
- フィルタはアコーディオン。
- カード一覧: 2列。
- 詳細モーダル: フルスクリーン、上部にバナー情報。

### 4.6 マイページ
- 最近の結果タイムライン（カードサムネ＋レア色ライン）。
- ピン留めカード: 横スクロール。
- 基本設定: テーマ切替スイッチ（ライト/ダーク）。

### 4.7 管理（CMS）
- 3カラムレイアウト: 左フォーム、中央スプレッドキャンバス、右JSONプレビュー。
- バナーCRUD: 期間ピッカー、プール選択、正逆比率スライダー（ツールチップに値）。
- スプレッド定義: キャンバス上でカードをドラッグ配置（座標値を下に表示）。
- 監査ログ: コード風テーブル（Monospace、差分カラーリング）。
