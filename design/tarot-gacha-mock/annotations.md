# Layout Annotations

## グリッド寸法まとめ

## 主要余白
- セクション上下余白: 96px (デスクトップ)、64px (モバイル)。
- バナー一覧カード間: 24px (デスクトップ)、16px (モバイル)。
- CTA固定パネル: コンテンツパディング24px。

## フレーム別寸法
### トップ
- ヒーロータイトル → サブタイトル: 16px。
- サブタイトル → CTA群: 32px。
- ヒーロービジュアルカード間: 12px重なり。

### バナー詳細
- ヘッダ情報ブロック: タイトル下16pxに期間、期間下24pxにピティバー。
- スプレッドタブ間: 16px。タブ内パディング24px。

### ガチャ演出
- カード間距離: 最小24px、ケルト十字クロスは中心カードと交差カードの重なり量16px。
- スキップボタン余白: 32px（右/上）。

### リザルト
- グリッドカード間: 24px。
- 詳細パネル内: タイトル→レアバッジ 12px、タブ→本文 24px、タグチップ間 8px。

### 図鑑
- フィルタバー内チップ間 12px。
- カード一覧列間 24px、行間 32px。

## コンポーネントライブラリページ構成
1. **Atomsセクション**: 4列カードで各アトム表示。背景深緑80%。
2. **Molecules**: 3列グリッド、各カードに説明テキスト。
3. **Organisms**: 横幅全体を使ったワイヤーフレーム風ボード。
4. **Templates**: 1440pxのブラウザモック内に画面を縮小表示。モバイル版は端末フレーム付きで右側に並置。

各セクションのタイトル余白: 上64px、下32px。

## ステートボード配置
- 左列: ボタン状態 (Primary/Secondary/Tertiary/Icon)。
- 右列: カード状態 (Idle/Hover/Revealing/Revealed)。
- 下段: フォーム・トースト・トグルのステート。
- 各セル幅220px、高さ160px、内部パディング16px。
