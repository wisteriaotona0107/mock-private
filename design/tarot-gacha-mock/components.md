## Templates
- **トップ**: ヒーロー + バナーリスト + CTA固定 + フッタ。
- **バナー詳細**: ヘッダ情報 + スプレッド選択 + CTAボード + モーダル。
- **演出**: スプレッドキャンバス + スキップボタン + 演出パーティクル。
- **リザルト**: リザルトグリッド + 詳細パネル + CTA。
- **図鑑**: フィルタバー + 図鑑一覧 + 詳細モーダル。
- **CMS**: 管理フォーム + スプレッドキャンバス + 監査ログ。

## ダーク/ライトテーマ規則
- ダーク: 背景 `#1B4332`、テキストエクリュ。カード: 深緑グラデ＋ゴールド縁。
- ライト: 背景 `#F4EDE4`、テキスト深緑。ゴールドはそのまま。シャドウは `rgba(27,67,50,0.25)`。
- 自動反転: 正逆アイコン・バッジのストロークカラーも反転。

## アクセシビリティメモ
- 全テキストコントラスト 4.5:1 以上。
- キーボードタブ順: ヘッダ→バナー→CTA→フッタ。
- ARIA: カードに `aria-pressed` で正逆状態を伝達。モーダルは `aria-modal="true"`。
