AGENTS.md

Working Principles

Read First

変更前に README と主要な architecture / operations / agents 文書を確認します。

Default Rule

迷ったら実装追加よりも、構造・責務・判断理由の明確化を優先します。

Safe Change

大きな変更ほど、先に docs を更新し、壊すより文書化して保留を優先します。

Before Changing Anything

  • ブランチ名と目的が一致しているか確認する。
  • git status で未コミット変更を確認する。
  • 対象領域の設計文書・決定メモの有無を確認する。
  • 変更の種類を小修正 / 設計変更 / 将来運用影響で分類する。

Documentation Update Rules

  • 役割や責務の変更 → docs/architecture/ と agents/
  • 開発フローの変更 → docs/operations/
  • 位置づけ変更 → README.md と docs/vision/
  • 重要な判断追加 → docs/decisions/
