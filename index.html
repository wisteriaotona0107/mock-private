SAKE CURATION

小規模飲食店のための日本酒セレクトを、視覚的にわかりやすく、すばやく更新できる形でお届けします。旬の銘柄から定番の一本まで、飲食店のストーリーに寄り添いながら提案できるよう、香り・味わい・造り手の背景までコンパクトに整理しました。

本サイトは HTML + Vanilla JavaScript の SPA として構築されており、日本酒一覧はサーバサイド API (GET /api/sakes) から取得します。API が利用できない場合はローカルのモックデータでフェイルセーフ表示を行い、情報の供給を止めません。

ご質問や掲載依頼は hello@sakecuration.jp までお気軽にどうぞ。

日本酒の飲み方

温度帯をデザインする

お燗から花冷えまで、銘柄ごとの適温をスタッフと共有しましょう。温度帯によって味のふくらみが大きく変わるため、提供時のストーリーを添えると印象に残ります。

酒器でテクスチャを操作

薄張りグラスで香りを生かすか、平盃で穏やかに広げるか。店の空間に合わせた酒器の選択が味わいの輪郭を際立たせます。

ペアリングをストックする

旬の食材との相性メモを 3 パターンほど用意しておくと、スタッフが自信を持って提案できます。特に塩味・旨味・酸味のバランスに注目しましょう。

TIP: テーブルオーダー用の QR メニューと連動させることで、常連客にも新しい日本酒体験をスムーズに届けられます。

おすすめのお店

酒縁 小町

東京・日本橋。旬の海鮮と共に四季の日本酒を 8 タップで提供。店主が毎週蔵元を訪ね、確かな情報を添えて提案します。

灯り坂

京都・祇園。町家をリノベーションした空間で、温度帯違いのペアリングコースが人気。酒器のセレクトも常に進化中。

霧の蔵

札幌・円山。北海道産の食材とローカル酒蔵の新作をマリアージュ。テイスティングノートを店内のモニターで共有しています。
